# El Pollo Loco

[English](#english) | [Deutsch](#deutsch)

## English

El Pollo Loco is a browser-based jump-and-run game built with Vanilla JavaScript and HTML5 Canvas. The player controls Pepe through a side-scrolling desert world, collects coins and bottles, defeats chickens by jumping on them, and fights an endboss at the end of the level.

This project focuses on object-oriented JavaScript, game state management, collision detection, and canvas rendering.

### Features

- Object-oriented game architecture
- HTML5 Canvas rendering
- Side-scrolling level with layered backgrounds
- Enemies, collectibles, status bars, and endboss mechanics
- Keyboard and mobile touch controls
- Sound effects, background music, mute, and fullscreen support
- Restart and home screen without page reload
- Responsive layout for desktop and mobile devices

### Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
- Object-Oriented Programming
- Browser APIs: Fullscreen, Dialog, Audio, Pointer Events

### Controls

- `←` / `→` Move
- `↑` or `Space` Jump
- `D` Throw bottle

Mobile devices use on-screen touch controls.

## Deutsch

El Pollo Loco ist ein browserbasiertes Jump-and-Run-Spiel, umgesetzt mit Vanilla JavaScript und HTML5 Canvas. Der Spieler steuert Pepe durch eine seitlich scrollende Wüstenwelt, sammelt Münzen und Flaschen, besiegt Hühner durch Sprünge und tritt am Ende gegen einen Endboss an.

Im Fokus des Projektes stehen objektorientiertes JavaScript, Game-State-Management, Kollisionserkennung und Canvas Rendering.

### Features

- Objektorientierte Spielarchitektur
- Rendering über HTML5 Canvas
- Seitlich scrollendes Level mit mehreren Hintergrundebenen
- Gegner, Collectibles, Statusleisten und Endboss-Mechanik
- Tastatursteuerung und mobile Touch Controls
- Soundeffekte, Hintergrundmusik, Mute- und Fullscreen-Funktion
- Neustart und Home-Screen ohne Seitenreload
- Responsive Darstellung für Desktop und mobile Geräte

### Technologien

- HTML5
- CSS3
- JavaScript
- Canvas API
- Objektorientierte Programmierung
- Browser APIs: Fullscreen, Dialog, Audio, Pointer Events

### Steuerung

- `←` / `→` Laufen
- `↑` oder `Leertaste` Springen
- `D` Flasche werfen

Auf mobilen Geräten stehen Touch Controls zur Verfügung.
